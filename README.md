## 📖 About

This repository documents my complete run through **[LeetCode's SQL 50 Study Plan](https://leetcode.com/studyplan/top-sql-50/)** — a curated set of 50 essential SQL interview questions, ranging from basic `SELECT` statements to advanced joins, subqueries, and string/regex functions.

The goal: build strong, interview-ready SQL fundamentals by solving every problem across all 7 topic areas, from Easy warm-ups to a Hard-level finale.

🏆 **Badge earned:** SQL 50 (LeetCode)
📅 **Prep time:** ~1 month
🎯 **Focus:** Joins, aggregation, subqueries, window-style logic, string/regex handling
